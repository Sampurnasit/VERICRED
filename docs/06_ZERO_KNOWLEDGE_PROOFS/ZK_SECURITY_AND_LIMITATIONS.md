## 1. Trusted Setup Ceremony & Toxic Waste Management

Groth16 zk-SNARKs require a two-phase structured reference string (SRS) setup:
1. **Phase 1 (Powers of Tau)**: Universal, circuit-independent ceremony. VERICRED utilizes the widely audited `powersOfTau28_hez_final_14.ptau` (Hermez / Polygon public ceremony with thousands of independent participants).
2. **Phase 2 (Circuit-Specific Setup)**: Binds the circuit R1CS constraints to proving and verification keys (`.zkey`).
   - In development: Executed locally with secure entropy.
   - In production: Requires a multi-party computation (MPC) ceremony with public contributions from participating university registrars to guarantee the "toxic waste" parameter $\tau$ is securely discarded.

## 2. Threat Analysis & Circuit Attack Vectors

### 2.1 Public Input Substitution Attack
- **Attack**: An attacker takes a valid proof generated by Student A ($x = 8.72, T = 8.0$) and replaces public input $T = 800$ with $T = 950$ or replaces $A_x, A_y$ with their own key.
- **Mitigation**: Groth16 proof verification mathematically incorporates the public inputs:
  $$\sum_{i=0}^4 u_i \cdot \frac{\beta u_i(x) + \alpha v_i(x) + w_i(x)}{\gamma}$$
  Altering any single bit of public inputs causes the pairing check $e(\pi_a, \pi_b) == \dots$ to fail decisively.

### 2.2 Proof Replay Across Job Applications
- **Attack**: An attacker intercepts a legitimate candidate's Groth16 proof submitted to Employer A and submits it to Employer B claiming it is their own.
- **Mitigation**:
  - Presentations include a verifier-specific challenge nonce $N$ and recipient domain identifier.
  - Future research (Post-MVP): Incorporating holder nullifiers or Schnorr proof-of-possession of the student's private wallet key inside the circuit.

### 2.3 Field Wraparound / Underflow Attack
- **Attack**: In $\mathbb{F}_p$, negative numbers wrap around ($0 - 1 = p - 1$). If the circuit used naive subtraction $x - T$, a candidate with $x = 200$ and $T = 800$ might exploit modular arithmetic if not bounded.
- **Mitigation**: `CgpaThresholdValidator.circom` explicitly enforces 14-bit binary decomposition (`GreaterEqThan(14)`). Numbers exceeding $14$ bits cannot be parsed, rendering field wraparound exploits impossible.
