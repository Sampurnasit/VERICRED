## 2. Fixed-Point Integer Representation

To eliminate floating-point non-determinism in arithmetic circuits, academic grade point averages are encoded as fixed-point scaled integers:

$$\text{Scale Factor } S_f = 100$$
$$x = \lfloor \text{CGPA} \times S_f + 0.5 \rfloor$$
$$T = \lfloor \text{Threshold} \times S_f + 0.5 \rfloor$$

**Concrete Example**:
$$\text{Actual Grade: } 8.72 \implies x = 872$$
$$\text{Required Minimum: } 8.00 \implies T = 800$$

### Domain Bounding Constraints
To prevent modular wraparound attacks in $\mathbb{F}_p$ (where a negative number $-1 \equiv p - 1$ could satisfy naive inequality checks), the circuit strictly enforces:
$$0 \le x \le 1000$$
$$0 \le T \le 1000$$

## 3. Cryptographic Commitment Model

The academic commitment $C$ is a 2-to-1 algebraic hash computed via the **Poseidon** cryptographic permutation over $\mathbb{F}_p$:

$$C = \text{Poseidon}_2(x, s)$$

Where:
- $x \in [0, 1000] \subset \mathbb{F}_p$: Private scaled CGPA.
- $s \xleftarrow{\$} \mathbb{F}_p$: Private 254-bit random blinding salt.
- $C \in \mathbb{F}_p$: Authenticated academic commitment (Public Signal).

## 4. Formal Proof Statement (Relation $\mathcal{R}$)

The zero-knowledge relation $\mathcal{R}_{\text{VERICRED}}$ proven by the student is formally defined as:

$$\mathcal{R}_{\text{VERICRED}} = \left\{ (u, w) \mid \text{ValidRelation}(u, w) = 1 \right\}$$

### Public Instance ($u$)
$$u = \big( C, T, A_x, A_y \big) \in \mathbb{F}_p^4$$
- $C$: Credential commitment.
- $T$: Eligibility threshold.
- $(A_x, A_y)$: BabyJubjub public key coordinates of the authorized issuing institution.

### Private Witness ($w$)
$$w = \big( x, s, R_{8x}, R_{8y}, S \big) \in \mathbb{F}_p^5$$
- $x$: Scaled integer CGPA.
- $s$: Blinding salt.
- $(R_{8x}, R_{8y}, S)$: Institutional EdDSA signature over commitment $C$.

### Conjunction of Invariant Conditions
The circuit evaluates to $1$ if and only if **all four** of the following conditions hold simultaneously:

1. **Commitment Soundness**:
   $$C - \text{Poseidon}_2(x, s) = 0$$

2. **Range Satisfaction (Eligibility Condition)**:
   $$x - T \ge 0 \iff \exists \Delta \in [0, 1000] \text{ s.t. } x = T + \Delta$$

3. **Input Range Enforcement**:
   $$\text{Num2Bits}_{14}(x) \in \{0, 1\}^{14} \quad \text{and} \quad \text{Num2Bits}_{14}(T) \in \{0, 1\}^{14}$$

4. **Cryptographic Institutional Binding**:
   The signature $(R_{8x}, R_{8y}, S)$ must be a valid EdDSA signature on point $A = (A_x, A_y)$ over message $M = C$:
   $$S \cdot B = R_8 + \text{Poseidon}_5(R_{8x}, R_{8y}, A_x, A_y, C) \cdot A$$
   where point additions and scalar multiplications occur over the BabyJubjub twisted Edwards curve.

## 5. Security Proof Guarantees

- **Zero-Knowledge Property**: The proof reveals zero knowledge of $w = (x, s, R_8, S)$ beyond the truth of the statement. The verifier cannot distinguish whether $x = 800$, $x = 872$, or $x = 1000$.
- **Computational Soundness**: No polynomial-time adversary can produce a valid proof $\pi$ if $x < T$ or if $(R_8, S)$ was not generated by private key $sk$ corresponding to $(A_x, A_y)$, except with negligible probability $\epsilon \le \mathcal{O}(2^{-128})$.
